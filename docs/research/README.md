# Research notes

Development notes written while reverse-engineering both games and designing PhantomRing. You don't need any
of this to build or play. They record what was verified, how, and against which exe build (Elden Ring 1.17.1,
MGSV 1.0.15.4), so later work can re-check it.

Placeholders used in paths:

| Placeholder | Meaning |
|---|---|
| `<steam-library>` | the Steam library folder holding `common/` and `compatdata/` |
| `<scratch>`, "the scratchpad" | throwaway scripts and outputs from a working session; not included |
| `<old-project>` | an earlier private attempt at the same idea; its lessons are in [prior-work.md](prior-work.md) |
| `<SkyCraft>` | a checkout of https://github.com/chasmlol/SkyCraft |
| `<fromsoftware-rs>` | a checkout of fromsoftware-rs (https://github.com/vswarte/eldenring-rs) |
| `<TGA-CT>` | a checkout of https://github.com/The-Grand-Archives/Elden-Ring-CT-TGA |
| `<capstone>` | a capstone Python package outside site-packages (see `CAPSTONE_PATH`) |
| `<steamid64>`, `<account-id>` | your Steam account's ids (save folders, `userdata/`) |

`data/` holds tables extracted from the two executables (imports, RTTI, Lua bindings), regenerated by the
scripts in `tools/` and `tools/re/`.
